Module 5: OLS in Observation-Space

Key Concepts: Model y = Xβ + ε; ŷ = P_X y where P_X = X(X'X)⁻¹X'; e ⊥ 𝒞(X).

Projection Matrix: P_X is idempotent (P² = P) and symmetric (P' = P)

Decomposition: TSS = ESS + RSS, where:

  • TSS = ∥y - ȳ1∥² (total sum of squares)
  • ESS = ∥ŷ - ȳ1∥² (explained sum of squares)
  • RSS = ∥e∥² (residual sum of squares)

R²: R² = ESS/TSS = 1 - RSS/TSS

Reference: Eggers [1] - OLS as orthogonal projection in observation space.

Module 7: Inference - t-tests and F-tests (Dual Perspectives)

Observation-space: Nested subspaces 𝒞(X₀) ⊂ 𝒞(X₁); F-test compares projection lengths.

Parameter-space: Restrictions Rβ = r; F-test measures distance to constrained set under (X'X)-metric.

F-statistic: F = [(RSS₀ - RSS₁)/(df₀ - df₁)] / [RSS₁/(n - p₁)]

t-statistic: t = β̂ⱼ / SE(β̂ⱼ) where SE(β̂ⱼ) = σ̂√[(X'X)⁻¹]ⱼⱼ

Geometric view: ∥P₁y - P₀y∥² measures extra explained variance
